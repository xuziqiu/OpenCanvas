# OpenCanvas 快捷键速查

适用版本：1.0.10。除特别说明外，画布快捷键只在未编辑文字时生效。在 macOS 语义中可把 `Ctrl` 理解为 `Command`；当前正式桌面交付目标为 Windows。

## 全局与历史

| 操作 | 快捷键 |
| --- | --- |
| 快速打开卡片或白板 | `Ctrl K` |
| 撤销 | `Ctrl Z` |
| 重做 | `Ctrl Y` 或 `Ctrl Shift Z` |
| 取消当前操作、关闭浮层或取消选择 | `Esc` |
| 删除当前选择 | `Delete` 或 `Backspace` |

## 工具

| 工具 | 快捷键 |
| --- | --- |
| 选择 | `V` |
| 平移 | `H` |
| 连线 | `C` |
| 新建卡片 | `N` |
| 新建自由文字 | `T` |
| 新建 Section | `G` |
| 新建嵌套白板 | `W` |

## 选择与编辑

| 操作 | 快捷键或手势 |
| --- | --- |
| 全选当前白板节点 | `Ctrl A` |
| 增减多选 | `Ctrl` + 点击卡片顶栏或对象 |
| 复制所选空间实例 | `Ctrl C` |
| 粘贴空间实例 | `Ctrl V` |
| 创建独立卡片副本 | `Ctrl D` |
| 为多个所选对象创建 Section | `Ctrl G` |
| 小步移动 | 方向键 |
| 大步移动 | `Shift` + 方向键 |
| 进入卡片编辑 | 点击卡片正文 |
| 只选中并拖动卡片 | 点击或拖动卡片顶栏 |
| 打开卡片右侧栏 | 双击顶栏空白处 |
| 退出编辑并取消文字选择 | 点击画布空白处或按 `Esc` |

## 画布导航与吸附

| 操作 | 快捷键或手势 |
| --- | --- |
| 以指针为中心缩放 | 滚轮 |
| 平移画布 | `Space` + 拖动，或平移工具拖动 |
| 框选 | 选择工具下从画布空白处拖动 |
| 增强吸附 | 拖动时按住 `Shift` |
| 临时关闭吸附 | 拖动时按住 `Alt` |
| 滚动卡片正文 | 卡片已选中、正文溢出且指针位于正文上时滚轮 |

## 编辑器

编辑器遵循常见富文本快捷键，包括 `Ctrl B` 粗体、`Ctrl I` 斜体、`Ctrl U` 下划线。输入 `/` 打开区块命令，输入 `[[` 建立卡片链接，输入 `@` 插入提及；选中文字后使用就地浮动格式栏。不同输入法会占用部分按键，输入法正在组字时 OpenCanvas 不拦截 `Esc` 等画布命令。
