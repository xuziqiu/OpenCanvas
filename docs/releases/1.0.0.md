## 建议手动验收顺序

1. 单击正文一次进入编辑；单击顶栏只选择，越过 3px 后才开始拖动。
2. 从卡片四边和四角缩放，确认吸附参考线、Section 40px 边距和撤销。
3. Ctrl + 顶栏复选，打开中文 Tidy Up，检查锁定对象不参与几何变化。
4. 创建连线，重接自动/四向端点，编辑在线标签，切换曲线/折线/直线、粗细和虚线。
5. 进入五层以内的嵌套白板并逐级返回，确认面包屑标题不跳动。
6. 打开右侧栏，再切换全屏并返回，确认手动折叠状态与滚动位置。
7. 在桌面移动根白板，在文件树移动/重命名 Markdown，确认白板引用仍有效。
8. Electron 版选择“导入 Heptabase / ZIP / Canvas…”，先检查预览，再决定是否确认。

## 明确边界

- Heptabase 官方 Markdown 导出可迁移笔记、目录和附件，但该格式不包含白板坐标、Section、连线与嵌套白板。

- 云同步、多人协作、移动端、PDF 深度标注、插件市场和日记不属于 1.0.0 核心交付。
- OneDrive/第三方文件占用、真实触控硬件与更多历史知识库版本仍属于后续兼容性矩阵。
