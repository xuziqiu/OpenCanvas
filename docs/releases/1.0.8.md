# OpenCanvas 1.0.8 交付记录

日期：2026-09-05  
交付定位：私有预览版

## 本版完成

- 新增 20 章《OpenCanvas 完整用户手册》，覆盖安装、数据模型、桌面、卡片、编辑器、画布、Section、连线、嵌套白板、文件与项目、导入导出、恢复、排障、升级、卸载和备份。
- 新增十分钟上手与完整快捷键速查。
- 用户手册以内置离线窗口提供，从左下角帮助按钮的快捷键窗口进入；支持章节导航、全文章节搜索、滚动和 `Esc` 关闭。
- 手册按需加载，生产构建中独立为约 30 KB 文件，不增加主界面首屏包体。
- 新增产品交付完整度审计，将首次使用、数据安全、升级迁移、签名、许可、诊断、反馈、无障碍和真实资料验证纳入完成定义。
- Windows 图标改用仓库内固定 ICO 资源，避免每次打包临时执行高内存 PNG 转换，图标视觉不变。
- 项目卫生检查关闭 Knip/Oxc 在 Node 22+ 上默认预留约 6 GB 地址空间的实验传输模式，使低可用虚拟内存环境下的构建不再随机失败。
