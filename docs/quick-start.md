# OpenCanvas 十分钟上手

适用版本：1.0.10。OpenCanvas 是一个本地优先的视觉知识工作区：卡片正文保存为 Markdown，白板只保存卡片的引用、位置、尺寸、Section、连线和视口。第一次启动会显示三步引导；关闭后仍可从设置重新打开。

## 1. 认识三个最重要的概念

- **卡片**是实际笔记文件。一张卡片可以同时出现在多个白板，也可以在同一白板出现多次。
- **白板**是空间组织视图。移动或删除白板上的卡片实例，不等于删除原始 Markdown 文件。
- **文件目录**是真实的笔记目录；白板层级是引用关系。改变其中一个，不会强迫另一个采用相同结构。

## 2. 创建第一块白板

1. 在左侧栏选择“桌面”。桌面本身也是一张可以缩放和平移的画布，放置所有根级白板。
2. 点击“新建白板”，输入名称。
3. 双击白板预览，或选中后打开，进入白板。
4. 左上角路径会显示当前白板的上级关系；点击上级名称或返回按钮可返回。

## 3. 创建和编辑卡片

1. 按 `N`，然后在画布单击使用默认尺寸，或拖出自定义尺寸。
2. 单击卡片正文会直接进入编辑状态；单击顶栏只选中卡片，随后可以拖动。
3. 在正文中输入 `/` 可打开区块命令；选择文字后可使用浮动格式栏。
4. 点击画布空白处退出编辑并取消文字选择。
5. 把指针移到卡片四边或四角，可直接调整尺寸，不必先选中。

## 4. 组织空间

- 按住画布空白处拖动可框选；`Ctrl` 点击卡片顶栏可增减多选。
- 多选后按 `Ctrl G`，可用合适边距创建 Section。
- 使用多选工具栏可对齐、均匀分布或整理为行、列、网格。
- 拖动时会出现临时参考线；按住 `Shift` 增强吸附，按住 `Alt` 临时关闭吸附。
- 按 `C` 或点击卡片顶栏的连线按钮，从临时出现的连接点拖向另一个节点。

## 5. 找到你的文件

桌面版默认知识库位于：

```text
文档/OpenCanvas Vault
```

在左下角点击知识库状态，选择“在资源管理器中显示”；也可在“设置”中切换知识库目录。切换目录不会自动移动或删除原目录。

## 6. 第一次使用后立即做一次备份

点击左下角知识库状态，选择“导出知识库 ZIP…”。OpenCanvas ZIP 能完整保留卡片、白板、Section、连线、嵌套关系和附件；普通 Markdown ZIP 或 Heptabase Markdown 导出不能保留空间布局。
